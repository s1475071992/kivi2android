# v0.3 Sonar DSP experiment
- Same Steam Audio 4.8.1 SDK, Android SDK 35, JDK17, Gradle 8.9, pinned NDK/CMake.
- Candidate points 1–32; selected points 1–32 (default 1), sequential / random / fixed first. Manual button queues one ping, automatic refresh is user-selected, with an anti-overlap cap. Reference is centered/dry, fixed 8 ms; each echo fixed 50 ms, sample-accurate delay, no duration coding. One pending ping maximum.
- Delay = 2*d/343 * factor; amplitude inverse distance with floor at 1m, applied once in DSP (not Steam Direct Effect). Monostatic Doppler (343+v)/(343-v), synthetic radial velocity and optional exaggeration; no static pitch encoding or velocity from point switching.
- Brightness: incidence cosine controls high-frequency content, not real material; local RMS geometry and wavelength-inspired roughness control 70 Hz modulation, equal pulse RMS normalization. Line/ring virtual normals, analytic cone-pit normal/residual, adjustable test overrides. HRTF binaural independently per active echo; bypass outputs mono. 
- Independent switches, blind shape practice (not controlled clinical experiment), default low volume, stop on activity background. No real camera/tracking/material acquisition. Not tested on physical device. Debug builds may require uninstalling older builds if signing keys differ.
- Tests: C++ delay/Doppler/gain/selection/fixed pulse RMS, JVM geometry and model, CI build, release asset integrity.
