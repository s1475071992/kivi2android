# v0.4.1 diagnostic patch
User reports 48 candidates but 6 audible. Source inspection did not prove a 6-cell limit. Add real Steam Audio native regression for full and sparse rasters, 48/256 cells, HRTF and mono. Add completed-slot and nonzero PCM counters plus AudioTrack submitted/played frames, underruns and write errors. Single manual scan is rendered as an immutable full PCM frame before streaming, to avoid real-time DSP starvation; automatic remains streaming. Diagnostic buttons configure 48 equal-distance 50 ms pulses in 100 ms slots, HRTF on/off. No claim that perception or physical device output is verified.
